## Upgrading Jostter Marinho

<Callout kind="info">
  Always back up your data before upgrading. Review breaking changes in each release above.
</Callout>

Follow these steps to upgrade smoothly.

<Steps>
  <Step title="Check Compatibility" icon="shield">

    Verify your current version and review migration notes.

  </Step>
  <Step title="Backup Data" icon="download">

    Export your documentation space via the dashboard at `https://dashboard.example.com/export`.

  </Step>
  <Step title="Run Migration" icon="settings">

    <CodeGroup tabs="Docker,CLI">
      ```bash
      docker pull josttermarinho:latest
      docker run --env API_KEY=YOUR_API_KEY josttermarinho:latest migrate
      ```
      ```bash
      npm install -g @jostter/cli
      jostter migrate --api-key YOUR_API_KEY
      ```
    </CodeGroup>

  </Step>
  <Step title="Restart Services" icon="refresh-cw">

    Restart your instance and test core features.

  </Step>
</Steps>

## Breaking Changes Examples

For v1.2.0, update your configuration to use the new auth format.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Old
  const config = { auth: { token: 'old-token' } };

  // New
  const config = { 
    auth: { 
      type: 'bearer', 
      token: `YOUR_TOKEN` 
    } 
  };
  ```
  ```python
  # Old
  config = {'auth': {'token': 'old-token'}}

  # New
  config = {
      'auth': {
          'type': 'bearer',
          'token': 'YOUR_TOKEN'
      }
  }
  ```
</CodeGroup>
